# Documentation Site

Capabilities / solution documentation site for **OneGrid on Microsoft Fabric**,
deployed as an Azure Static Web App.

- **Live:** https://kind-tree-0d63b6a0f.7.azurestaticapps.net/home.html
- **Azure SWA:** `pm-fabric-site` in resource group `rg-esite`

## What's here

A tiny zero-dependency Node static-site generator. Content lives in `_pages_*.js`
modules; `_build.js` holds the shared CSS/JS, navigation and page/section helpers and
emits self-contained HTML (CSS inlined, diagrams as inline SVG — no CDNs).

```
_build.js            # generator: CSS/JS, NAV_GROUPS, page()/section()
_pages_*.js          # one module per content page
*.svg                # inline diagrams (incl. ontology-graph.svg)
logo.svg
staticwebapp.config.json   # SPA fallback to /home.html
*.html               # built output (regenerated by _build.js)
```

Pages: Home, Business Value, Architecture, Data Foundation, Real-Time Intelligence,
ML Pipeline, Survival Models, Anomaly Detection, Model Comparison, **Knowledge Graph**,
**3D Digital Twin**, **Failure Simulation**, Data Dictionary, Operations.

`ontology-graph.svg` is generated from `report-app/server/ontology.json` (the same
ontology the app serves), so the docs match the live knowledge graph.

## Build

```powershell
cd docs-site
node _build.js            # rewrites all *.html in place
```

## Deploy

Build a clean deploy folder (everything except the `_*.js` sources), then push with the
Azure Static Web Apps CLI. The deployment token is fetched from Azure — never commit it.

```powershell
# 1. build
node _build.js

# 2. clean dist (html + svg + config only)
Remove-Item dist -Recurse -Force -ErrorAction SilentlyContinue
New-Item -ItemType Directory dist | Out-Null
Get-ChildItem -File | Where-Object Name -notlike '_*.js' | Copy-Item -Destination dist

# 3. get token + deploy
$env:SWA_CLI_DEPLOYMENT_TOKEN = az staticwebapp secrets list `
  --name pm-fabric-site --resource-group rg-esite --query "properties.apiKey" -o tsv
swa deploy .\dist --env production --deployment-token $env:SWA_CLI_DEPLOYMENT_TOKEN
```

> `dist/` is a build artifact and is gitignored.

## Intro trailer (splash)

The home page opens with a full-screen **splash trailer** (`media/PM_OGE_Trailer.mp4`,
`media/trailer-poster.jpg`) that autoplays muted, plays **once per browser session**
(sessionStorage), respects `prefers-reduced-motion`, and offers **Unmute** / **Enter site**
plus a **Replay trailer** button. It is injected only into `home.html` by `_build.js`.

The bundled MP4 is a web-optimized re-encode (H.264, 1080p, faststart) of the source
trailer, tracked via Git LFS. To refresh it from a new source:

```powershell
ffmpeg -i <source>.mp4 -c:v libx264 -preset medium -crf 27 -pix_fmt yuv420p `
  -vf "scale=1920:-2" -c:a aac -b:a 128k -movflags +faststart docs-site/media/PM_OGE_Trailer.mp4
ffmpeg -ss 2 -i docs-site/media/PM_OGE_Trailer.mp4 -frames:v 1 -q:v 3 docs-site/media/trailer-poster.jpg
```

`.mp4` is mapped to `video/mp4` via `staticwebapp.config.json` mimeTypes.
